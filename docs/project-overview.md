# Project Overview

## Project Name

Strength Assistant

## Executive Summary

This project is a mobile application designed to assist users with their strength training workouts. It is built using React Native and Expo, with Supabase providing the backend infrastructure. The application allows users to manage exercises, log workouts, and track their progress.

## Technology Stack Summary

| Category   | Technology          |
| :--------- | :------------------ |
| Language   | TypeScript          |
| Framework  | React Native (Expo) |
| Backend    | Supabase            |

## Repository Structure

The project is a **monolith**, with all the code for the mobile application contained within this single repository.
